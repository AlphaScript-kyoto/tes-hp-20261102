# NAGI hair atelier — 美容室ホームページ制作デモ

京都の架空の美容室「NAGI hair atelier」を想定した、レスポンシブ対応の1ページ型ホームページです。

## 開き方

1. ZIPファイルを解凍します。
2. 解凍した `NAGI_hair_atelier_demo` フォルダの `index.html` をダブルクリックしてください。
3. Chrome、Edge、Safariなどのブラウザで表示されます。

Webサーバーやインストール作業は不要です。画像・CSS・JavaScriptを含めてオフラインで表示できます。

## 収録ファイル

```text
NAGI_hair_atelier_demo/
├── index.html                 トップページ
├── README.md                  この説明ファイル
└── assets/
    ├── css/
    │   └── style.css          レイアウト・色・スマホ対応
    ├── js/
    │   └── main.js            スマホメニュー・予約フォームのデモ動作
    └── img/
        ├── favicon.svg        ブラウザアイコン
        ├── hero-portrait.webp メインビジュアル
        ├── salon-space.webp   サロンのイメージ
        ├── style-*.webp       ヘアスタイル3点
        ├── staff-*.webp       スタッフ2点
        └── *.svg              各イラストのベクター原本
```

## 内容

- トップ（メインビジュアル）
- コンセプト・3つのこだわり
- メニューと料金（サンプル価格）
- ヘアスタイルギャラリー
- スタッフ紹介（架空人物）
- よくあるご質問
- アクセス（架空の所在地・イラスト地図）
- 予約フォーム（動作確認用）
- PC・スマホに対応したナビゲーション

## 修正のしかた

- **文章・メニュー料金：** `index.html` をテキストエディタで修正
- **色・文字・余白：** `assets/css/style.css` の冒頭の `:root` や各スタイルを修正
- **動作：** `assets/js/main.js` を修正
- **写真への差し替え：** `assets/img/` に任意の画像を置き、`index.html` 内の該当する画像パスを書き換える

## 重要：テスト用サイトです

- 店舗名、所在地、スタッフ、営業時間、メニュー、料金はすべて架空・サンプルです。
- **予約フォームは送信しません。** 入力内容を同じページ内で確認表示するだけで、サーバーへの通信や個人情報の保存は行いません。
- 本番運用には、正式な店舗情報への差し替え、予約サービスやサーバーとの連携、プライバシーポリシー等の整備が必要です。
- 画像はこのデモ用に制作したオリジナルのイラストです。外部の画像APIには依存しません。
